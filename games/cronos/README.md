# Cronos: The New Dawn adapter

Steam app ID: `2101960`. The surveyed Steam install contains
`Cronos/Content/Paks`. [Nexus mod 38](https://www.nexusmods.com/cronosthenewdawn/mods/38)
instructs users to unpack its `Mods` folder into that directory. This is the
first supported archive shape for OmaMods' Nexus downloader and installer.

OmaMods installs `.pak`, `.utoc`, and `.ucas` files beneath the archive's
`Mods` folder. It also recognizes the single flat, same-stem
`.pak`/`.utoc`/`.ucas` triplet found in mod 38's current ZIP and places it
under `Paks/Mods`. It keeps the downloaded archive in persistent user storage,
checks paths and collisions before writing, records installed file hashes, and
can revert files it still owns. It will not overwrite existing game files.
Archives that contain loaders, scripts, or executable files are rejected as a
whole. The installer is shared with Stellar Blade, so an archive holding one
asset folder installs as `Mods/<folder>/`, and one with several variant folders
needs `--option`. Without an API key, download manually and run
`omamods nexus install cronos <mod-id> <archive>`.

Nexus uses a personal API key for personal/testing clients. Premium users can
request a download link with that key; non-premium users must also supply the
short-lived `nxm://` link generated by the site's **Mod Manager Download**
button. The actual key and mod selection live in a private user config outside
this repository. See the root README for setup and commands.
